# MeetDigest — сборки приложений

Здесь публикуются только готовые сборки MeetDigest. Исходного кода здесь нет.

MeetDigest записывает встречу, отправляет её на сервис и возвращает конспект.

## Android

1. Откройте [последний выпуск](../../releases/latest) и скачайте файл `meetdigest-*.apk`.
2. Разрешите установку из этого источника: Android спросит об этом сам.
   Если не спросил — «Настройки → Приложения → Особый доступ → Установка
   неизвестных приложений».
3. Установите APK поверх прежней версии. Очередь записей и настройки сохранятся.

Дальше приложение обновляется само: оно видит новый выпуск, скачивает его,
сверяет контрольную сумму (sha256) и предлагает установить.

## Проверка файла

Рядом со сборкой лежит `latest.json`. Поле `sha256` в нём должно совпадать с
контрольной суммой скачанного APK.
